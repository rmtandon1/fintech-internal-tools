Build or buy

Build, one app at a time, if you'll own the engine

What the demo shows

  • Rules added, switched off and removed, each one reviewed
  • A manual check replaced by a lookup
  • A new app that inherits the same controls

What it doesn't

  • Sign-on, hosting, backups and on-call
  • Business users building without an engineer
  • Production data and load

Where it could go wrong

  • Formulas nobody wrote down, applied to money
  • Reviews that turn into rubber stamps
  • Savings absorbed by engineers and hosting

Next 90 days

  1. Name an engine owner and a second reviewer
  2. Move Chargebacks; run it beside the Power App
  3. Go or stop on parity, review time and cost per change

Where Devin fits

  • If you build: writes each change; engineers approve and merge
  • If you stay: custom connectors, tests and docs for flows
