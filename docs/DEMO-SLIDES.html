Honest assessment and recommendation

Build the governed core with Devin, in stages. Retire Power Apps app by app.

Replicable with Devin

  • Apps on one shared engine: three live, Chargebacks started from its export
  • Rules and approvals with maker-checker: added, switched off and removed
  • Connectors written from public API docs, tested on recorded responses
  • Admin plane: roles, live settings, masked data and one audit log across apps

Not replicable, or not shown

  • Self-service: business users no longer build alone; every change needs an engineer
  • The platform: SSO, hosting, deploy pipeline, backups and on-call are not built yet
  • Microsoft 365 reach: Teams, Outlook, SharePoint and mobile each become code you own
  • Accountability: engine design and security sign-off stay with named engineers

Where the risk lies

  • Migration tail: undocumented formulas that behave differently on money
  • Review at volume: a five-minute review is only as good as the tests and the reviewer
  • Cost is unproven: licences go; engineers, hosting and Devin usage arrive
  • Thin evidence: one demo, seeded data and test APIs, not production load
Recommendation
Build, behind a 90-day gate

The pain is rules on money that change often, span apps and need review. Owned code does that well; Power Apps doesn't.

  1. Weeks 0–4: name an engine owner and a second reviewer. Decide SSO, hosting, database and deploys.
  2. Weeks 4–12: finish Chargebacks. Run it alongside the Power App and compare every decision.
  3. Day 90 gate: parity, review time, no unreviewed change, cost per change. Pass, then move apps by risk and licence cost.

Where Devin fits if you build

  • Builds the platform pieces your engineers decide: SSO, deploys, database
  • Moves each app: a first pull request, then small requests from its list
  • Makes every later rule, check and removal, reviewed like today
  • Never approves, never merges alone, never owns the engine

If you buy: stay on Power Apps, or move to another platform

  • Add governance: managed environments, solutions in source control, approval pipelines
  • Devin's role is smaller: custom connectors such as Companies House, and tests and docs for flows
  • The review gap remains wherever the platform still allows live edits
