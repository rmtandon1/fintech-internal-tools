Build or buy

Build it yourselves, one app at a time, with one engineer in charge

What the demo proves

  • Rules can be added, turned off and removed, and an engineer checks each change
  • A manual check can be replaced with an automatic one
  • New apps get the same security from day one

What it doesn't prove

  • Login, hosting, backups and support aren't built yet
  • Business users can't make changes themselves any more
  • It hasn't run on real data or at real volume

Risks

  • Undocumented Power Apps formulas may work differently once moved
  • Reviews can get rushed as the number of changes grows
  • Engineering and hosting costs could cancel out the licence savings

Next 90 days

  1. Pick one engineer to own the system, and a second to review
  2. Move Chargebacks and run it alongside the Power App
  3. Decide: does it match, how long do reviews take, what does each change cost?

Where Devin fits

  • If you build: Devin writes the changes. Your engineers review and approve them.
  • If you stay on Power Apps: Devin can still build custom connectors and write tests and documentation.
